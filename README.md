Astra 是一个可交互的霓虹星系作品：4,500 个星尘粒子组成四条旋臂，在深空背景中沿轨道缓慢流转，留下连续运动拖尾与青蓝、紫罗兰、粉色和暖白色光晕。移动鼠标可牵引附近星尘，点击或轻触空白区域会释放椭圆冲击波，将附近粒子推离轨道，随后逐渐回归；向下滚动时镜头深入星系中心，标题逐字浮现并发光。页面提供响应式布局、动画暂停按钮和系统减少动态效果偏好支持，无需外部图片、字体或脚本。

全部 HTML、CSS 和 JavaScript 内联于 index.html，下载后直接用现代浏览器打开即可运行，无需安装依赖或构建。Canvas 2D 使用按 devicePixelRatio 缩放的绘图缓冲区、缓存径向渐变精灵与 lighter 混合实现高清霓虹效果；requestAnimationFrame 配合时间差、指数透明度拖尾、最长 0.05 秒的时间步及不超过 1/60 秒的物理子步更新动画。四旋臂参数模型提供持续移动的目标轨道，带阻尼弹簧负责扰动后的回归，软化引力及限速径向冲量处理鼠标互动；滚动驱动 1.00× 至 3.60× 镜头缩放，IntersectionObserver 驱动可访问的逐字标题动画。后台标签页停止调度，减少动态效果模式默认暂停，冲击波队列最多保留 8 个，触摸滚动不拦截默认行为。
